# 광주대학교 오늘의 학식 — Vibe Coding v2

이 버전은 광주대학교 공식 홈페이지의 `진월광장 > 식당메뉴` 게시판에서
최신 주간 식단 게시글과 엑셀 첨부파일을 찾아 읽는 연습용 프로젝트입니다.

## 1. 준비
Mac에서 터미널을 열고 이 폴더로 이동합니다.

예:
```bash
cd ~/Downloads/gwangju-meal-vibe-v2
```

## 2. 가상환경 만들기
```bash
python3 -m venv .venv
source .venv/bin/activate
```

## 3. 필요한 패키지 설치
```bash
pip install -r requirements.txt
```

## 4. 실행
```bash
python app.py
```

터미널에 표시되는 주소 중 아래 주소를 브라우저에서 엽니다.

http://127.0.0.1:5000

## 현재 단계
- 광주대학교 공식 식당메뉴 게시판 접속
- 최신 주간 식단 게시글 탐색
- 게시글의 엑셀 첨부파일 탐색
- 엑셀 다운로드
- 첫 번째 시트의 셀을 웹 화면에 표시

## 왜 바로 '오늘의 메뉴' 카드로 만들지 않았나요?
광주대학교가 올리는 엑셀의 실제 셀 구조를 먼저 확인해야 날짜, 메뉴명,
가격 등의 위치를 정확히 매핑할 수 있기 때문입니다.

앱을 한 번 실행한 뒤 화면에 나온 식단표 구조를 확인하면,
다음 단계에서 `월~금 날짜 선택 → 해당 날짜 학생정식만 카드로 표시`하도록 바꿀 수 있습니다.

## 문제가 생길 때
학교 홈페이지의 HTML 구조나 첨부파일 다운로드 방식이 변경되면
`app.py`의 `get_latest_post()` 또는 `find_excel_attachment()` 부분을 수정하면 됩니다.
